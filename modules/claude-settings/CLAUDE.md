# How to talk to me

Write plainly, even about technical topics. I know the technologies we work
with, so when I say something's unclear, it's the wording, not the subject
matter.

- Don't invent compact abstract terms ("ambient help," "load-bearing,"
  "disarm hazard") to save yourself a few words. Say the plain version.
- If a technical term genuinely earns its place, define it in the same
  sentence — don't assume it lands on its own.
- Shorter sentences. Don't stack multiple qualifiers or clauses together.
